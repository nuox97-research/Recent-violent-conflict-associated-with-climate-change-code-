#  Overview   
This repository contains all analysis and statistical modelling code to reproduce the results presented in the paper "Recent violent conflict associated with climate change"

#  Software dependencies 
All the data analyses were done with Matlab version 2024a. Statistical modelling was performed using R software (version 4.5.1) with the fixest package version 0.14.2.
All scripts in this repository are self-contained and can be run directly to reproduce the published outputs. No additional data compilation steps are required before execution.

# Typical workflow
1. Ensure MATLAB R2024a and R 4.5.1 are installed on your system.
2. Install the `fixest` package in R.
3. Run the MATLAB scripts for data analysis and figure generation.
4. Run the R scripts for statistical modelling.
